This project presents the \textit{Next-Generation AI-Driven Smart Education Management System}, a multi-institution web-based ERP platform for colleges, universities and polytechnic institutes. The objective is to unify the core academic and administrative operations of an institution, including student and teacher records, attendance, examinations, finance, hostel, library, inventory and human resources, in one secure system supported by artificial intelligence. The system is designed as four independently deployable applications: a Next.js frontend with a 32-module administration panel and student and guardian portals; a Node.js Core API that handles authentication, role-based access control, institution-level data isolation and business logic; a Python AI service that predicts student academic risk and GPA using machine learning; and a Python Voice service that provides a text and voice assistant running on a locally hosted language model. Questions the assistant cannot answer are sent to responsible staff, and their answers are used only after an administrator approves them. The Core API and the Voice service share one PostgreSQL database, and the system runs with Docker Compose. Each backend service has its own automated test suite. The project shows that daily institutional management and AI-based prediction and assistance can be combined in a single modular, multi-tenant platform.
